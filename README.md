# Jako Welcome Screen

חבילת אתר סטטית המוכנה לפריסה ב-Vercel. אין צורך ב-Backend או בתהליך Build.

## פריסה

1. חלץ את קובץ ה-ZIP.
2. העלה את כל התיקייה ל-Vercel או הרץ מתוכה `npx vercel --prod`.
3. אם Vercel מבקש Framework Preset, בחר `Other`.
4. השאר את Build Command ריק ואת Output Directory כ-`.`.

חשוב להעלות את כל ארבעת קובצי האתר יחד. `index.html` משתמש בסרטון, בלוגו ובתמונת הפתיחה שנמצאים לצדו.
